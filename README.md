A modern, responsive, and premium web application designed for **LifeCare Hospital**, a premier multi-specialty healthcare institution. Built with a clean **Blue + White** clinical color palette, smooth micro-animations, glassmorphism cards, and interactive healthcare tools.

---

## 🌟 Key Features

- **🚨 24/7 Emergency & Trauma Hotline:** Quick-dial hotline (`1-800-LIFE-CARE`) with live pulsing status indicators.
- **🚑 Live Ambulance Dispatch Simulator:** Interactive booking and tracking of mobile ICU units with real-time ETA updates.
- **📅 Interactive Appointment Booking Engine:**
  - In-person clinic vs. Tele-health video consultation toggle.
  - Dynamic doctor selection filtered by clinical department.
  - Interactive date picker and time slots (Morning, Afternoon, Evening).
  - Instant digital appointment confirmation pass with printable ticket and unique token ID.
- **🔬 Patient Diagnostic Lab Portal:**
  - Look up laboratory and imaging test results by Patient ID (try demo IDs: `LC-84920`, `LC-55102`, `LC-99314`).
  - View verified digital pathology sheets with biological reference ranges and flags.
- **👨‍⚕️ Specialist Doctors Directory:** Search physicians by name or filter by department, view clinical credentials, consultation fees, and book directly.
- **🏥 Clinical Centers of Excellence:** In-depth department cards for Cardiology, Neurology, Orthopedics, Pediatrics, Oncology, and Emergency Medicine.
- **🏢 World-Class Infrastructure:** Showcasing Robotic Operating Suites, 3T MRI, Level III ICUs, Automated 24/7 Pharmacy, and Cashless TPA Desk (45+ carriers).
- **💬 Interactive AI Health Assistant:** Floating chat widget equipped with smart replies for common inquiries (appointments, emergency, visiting hours, lab reports).
- **📱 Fully Responsive Design:** Optimized for mobile phones, tablets, laptops, and ultra-wide screens.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
3. Or run a local HTTP server:
   ```bash
   # Python 3
   python -m http.server 3000
   ```
   Then visit `http://localhost:3000` in your browser.

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Push this repository to GitHub.
2. Go to your GitHub repository **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root` folder.
4. Click **Save**. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/<repo-name>/`
